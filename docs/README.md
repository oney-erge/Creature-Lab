# Documentation

Start with the launcher (see the root [README](../README.md) for the exact commands), then use
the topic docs below when you need more detail.

## Reading Order

1. [Browser app](WEB_APP.md) - the app that opens first: real robots, 3D replays, check-ups.
2. [Robot check-up](ROBOT_CHECKUP.md) - shove real robots and get their falls explained.
3. [Getting Started](GETTING_STARTED.md) - first run, zoo, improvement, and troubleshooting.
4. [Build Editor](BUILD_EDITOR.md) - browser setup screen for creating CreatureSpec JSON.
5. [Concepts](CONCEPTS.md) - the mental model behind specs, tasks, traces, and backends.
6. [CLI Reference](CLI_REFERENCE.md) - commands grouped by workflow.
7. [Creature Spec](CREATURE_SPEC.md) and [Task Spec](TASK_SPEC.md) - JSON authoring.
8. [Run Artifacts](RUN_ARTIFACTS.md) - saved traces, reports, and reproducibility.
9. [Zoo](ZOO.md) - packaged creatures, tasks, baselines, benchmarks, and gallery.
10. [Failure Lab](FAILURE_LAB.md) - three reproducible education exercises.
11. [Known Issues](KNOWN_ISSUES.md) - latent gaps and deliberate limitations found in review.
